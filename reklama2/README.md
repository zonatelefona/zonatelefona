# ZONA TELEFONA: reklama v2 (narandžasta edicija)

Agresivan motion design u narandžasto-crnom stilu: kinetička tipografija sa EXTRA BOLD (Montserrat 900) slovima u 3D prostoru, 3D telefoni (u stilu iPhone-a i Samsung-a) sa narandžastim ivičnim svetlom, udarni talasi, svetlosne eksplozije, varničenje i motion blur. Muzika i sound design su originalni, 120 BPM, E-mol, i svaka reč ima svoj udarac.

| Vreme | Scena |
|---|---|
| 0–3 s | Energija se pali → **IMAŠ / TELEFON?** |
| 3–7 s | Narandžasti telefon izleće iz dubine → **KUPUJEMO!** · Otkup telefona |
| 7–11 s | Tri telefona uleću → **PRODAJ. / ZAMENI. / KUPI.** |
| 11–16 s | Showcase + laserski sken → **BRZA PROCENA. / FER CENA.** |
| 16–21 s | Telefoni prolaze kroz kadar → **TVOJ SLEDEĆI / TELEFON / JE OVDE.** + build-up |
| 21–27 s | Reveal brenda **ZONA TELEFONA** · KUPOVINA • OTKUP • ZAMENA · RUMA · @zona.telefona |
